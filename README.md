# Nexus | IT Service Desk

Nexus is an interactive IT Service Desk application designed to organise support requests, track ticket progress, and monitor service-level agreement (SLA) compliance through a centralised dashboard.

Built using Python, Streamlit, SQLite, Pandas, and Plotly, the application demonstrates a practical approach to ticket management and support operations.

## Project Overview

Support teams need a structured way to record issues, monitor their status, prioritise requests, and identify tickets that exceed their target resolution timelines.

Nexus brings these activities together in a simple interface, allowing users to create tickets, manage existing requests, monitor SLA performance, and review ticket statistics.

## Key Features

- **Ticket Creation:** Record support requests and maintain ticket information.
- **Ticket Management:** View existing tickets and update their status throughout the resolution process.
- **Priority Tracking:** Organise tickets by High, Medium, and Low priority.
- **SLA Monitoring:** Track tickets against configured time targets:
  - High priority: 4 hours
  - Medium priority: 8 hours
  - Low priority: 24 hours
- **SLA Status Indicators:** Identify tickets that are within SLA, have breached SLA, or have been resolved.
- **Interactive Dashboard:** Visualise ticket distribution, status, priority, and SLA performance.
- **Resolution Tracking:** Record resolution timestamps when tickets are resolved.
- **CSV Export:** Export ticket data for reporting and further analysis.

## Technology Stack

| Technology | Purpose |
|---|---|
| Python | Application logic and data processing |
| Streamlit | Interactive user interface |
| SQLite | Ticket data storage |
| Pandas | Data handling and processing |
| Plotly | Interactive charts and visualisations |

## Application Workflow

1. Create a support ticket with the relevant details.
2. Review and manage tickets through the ticket management interface.
3. Track ticket priority, status, and SLA compliance.
4. Update tickets as their status changes.
5. Review dashboard summaries and export ticket data when required.

## Getting Started

### Prerequisites

- Python installed on your system.
- Git installed on your system.

### Installation

Clone the repository:

```bash
git clone https://github.com/TEJASWI0G/IT-Service-Desk.git
```

Navigate to the project directory:

```bash
cd IT-Service-Desk
```

Install the required dependencies:

```bash
pip install streamlit pandas plotly
```

Run the application:

```bash
streamlit run app.py
```

**Note:** Adjust the repository URL, directory name, or application filename in these commands if your actual repository uses different names. Install any additional dependencies required by your project.

## Project Purpose

Nexus was developed as a practical project to explore how ticket management, priority-based tracking, SLA monitoring, and operational dashboards can support a structured IT service desk workflow.
